# Quick Triage

Use this as the entry path for a bounded lookup or an initially simple question.
Follow [execution modes](../references/execution-modes.md) for mode selection,
collection checkpoints, escalation and ending outcomes. A tool count is not a
success criterion.

1. Identify the exact question, requested precision and relevant time. Infer
   already supplied context; ask only for information necessary to proceed.
2. Apply the relevant safety gate. People and other guarded work still require
   the safety policy; official wanted/fugitive work must use its dedicated gate
   and deep mode.
3. Inspect supplied evidence or the most direct authoritative source first.
   Use the smallest useful source/tool set; do not manufacture research
   questions, alternate hypotheses or tool choices to fill a quota.
4. Check that the evidence identifies the right entity, time and requested
   fact. Check a credible alternative or contradiction if one exists. A direct
   source can resolve a low-ambiguity lookup without a separate search ritual.
5. For images/video, make a brief full-frame pass, then inspect the most useful
   regions as needed. Use the [visual workflow](image-video-geolocation.md) to
   distinguish coarse location from precise scene or viewpoint verification.
6. Stop when the requested conclusion is supported. If material ambiguity
   remains, apply the execution-mode checkpoint before expanding the work.

Default output: answer, supporting source(s), and any material uncertainty.
Create a persistent ledger or a full report only when complexity, continuity,
audit needs or the user's requested deliverable justify it. An uncertain or
blocked result is a valid ending outcome; do not invent precision.
