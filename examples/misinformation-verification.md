# Example — Misinformation Verification

## Claim

“A video shows event X happening in city Y today.”

## Tests

1. Locate the earliest upload and original file.
2. Extract keyframes and run multiple reverse searches.
3. Compare landmarks, road signs, language, weather, shadows, and audio.
4. Check whether the same video appeared before the claimed date.
5. Search official local sources and independent local reporting.
6. Distinguish upload time, recording time, and event time.

## Verdict format

- Supported / Misleading / Unsupported / False / Unresolved
- Confidence
- What is verified
- What is inferred
- What remains unknown
- Source table
